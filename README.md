Dell BIOS Secure Boot 2023 Certificate Compliance Report

This report identifies all Dell workstations that require a BIOS update to support the new Microsoft 2023 Secure Boot Certificate (the 2011 certificate expires in June 2026).

It displays:
- Current BIOS version vs. Dell’s minimum required version
- Status: GOOD (green), BAD - Update BIOS (red), or N/A (for unsupported models)
- Color-coded background for quick visual scanning

Purpose: Help prioritize BIOS updates before the Secure Boot certificate expiration.
-----------------------------------------------------------------------------------------------
